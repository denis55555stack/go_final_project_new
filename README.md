# Описание проекта
Проект был выполнен в рамках итогового задания по курсу "Go-разработчик с нуля".
В этом дипломном проекте реализован веб-сервер, который предоставляет функциональность планировщика задач. Сервер позволяет создавать, редактировать, удалять задачи и отмечать их как выполненные. В проекте используется REST API, а все данные хранятся в базе данных SQLite.

# Структура проекта
* go_final_project-main: корневая директория с проектом.
* go.mod: файл для управления модулем Go.
* go.sum: файл с управлением зависимостями для Go.
* scheduler.db: база данных для хранения задач.
* main.go: входной файл приложения.
  
* Структура директорий
* pkg: содержит следующие директории:
- server:
- server.go: файл, запускающий сервер.
* db:
- task.go: реализует функции для добавления, удаления, получения и обновления задач.
- db.go: отвечает за создание базы данных.
* api:
- addtask.go: содержит хендлеры для обработки запросов.
- api.go: регистрирует API-обработчики.
- nextdate.go: реализует функцию вычисления следующей даты и ее обработчик.
* tests: директория с тестами для проверки API, реализованного в веб-сервере.
* web: содержит файлы фронтенда проекта.

# Дополнительная информация
Задания со звездочкой не выполнялись, также Docker не использовался в проекте.
Для проверки заданий без звездочек тесты запускаются с помощью команды go test ./tests.
